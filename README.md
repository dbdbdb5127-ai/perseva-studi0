# PERSEVA 목걸이 조합실

부품을 골라 목걸이 조합을 3D로 짜 보는 내부 작업용 웹앱. 주소: https://dbdbdb5127-ai.github.io/perseva-studi0/

- 부품 사진·가격 출처: 대표 체크 부품 카탈로그(판매처 상품 페이지)
- 파일: index.html(앱), parts.json(부품 목록), cut/(펜던트 누끼), thumb/(원본 상품 사진 축소)
